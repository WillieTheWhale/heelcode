## Research information

### Project description

Design and implement mechanisms for easy creation of course-specific LLM agents for assignment help. The project will consist of two main components. The first is a policy engine, which will ingest course knowledge and generate a set of rules governing the types of allowed LLM. This tool will automatically pull course content from various sources and produce an AI policy for the instructor, which can be used in downstream AI tools. The second mechanism would be a prompt classifier, whose goal is to determine the pedagogical quality of a student's LLM prompt and only allow prompts that are conducive to learning and consistent with the instructor's AI policy. If a prompt is rejected (for example, if the classifier thinks that it would give away too much information), the classifier would provide the student with feedback on how they could improve their prompt to better align with the course goals. These two mechanisms would then be incorporated into a course-specific LLM harness that instructors could provide to their students for assignment help.
