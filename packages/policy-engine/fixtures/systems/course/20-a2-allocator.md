# Assignment a2: Allocator tests

Build a black-box test suite for a provided memory allocator. Boundary conditions and executable test construction are the assessed skills. Submit tests and a rationale.

## AI policy — September 3, 2026
Inherit the syllabus policy, with no permission to generate executable tests. AI can explain allocation concepts and discuss categories of edge cases without producing runnable tests. AI-generated test code, solution pseudocode, implementation code, whole solutions, and submission-ready rationales are prohibited. Debugging the student's own test requires the student's actual attempt or an observed failure.
